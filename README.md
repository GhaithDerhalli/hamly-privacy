# Life Cycle — Privacy Policy

Static privacy policy for the **Life Cycle (دورة حياة)** mobile app.

## Deployment (Railway)

Railway auto-detects Node.js from `package.json` and runs `npm start`, which serves
this directory with the [`serve`](https://www.npmjs.com/package/serve) static server
on the port Railway provides via `$PORT`.

- Entry point: `index.html`
- Account deletion anchor: `index.html#delete-account`
- Contact: lifecycleapp.support@gmail.com

## Local preview

```bash
npm install
npm start
# open http://localhost:3000
```
